# layswitch

Автоматическое переключение раскладки en/ru/uk для KDE Plasma на Wayland (аналог Punto Switcher / Caramba).
Набрал `ghbdtn` и пробел — получил `привет`, а раскладка переключилась на русскую.

## Как работает

- Демон захватывает физические клавиатуры через evdev (`EVIOCGRAB`) и пересылает все события
  в виртуальную клавиатуру через `/dev/uinput`. Поэтому он работает под Wayland, где обычные программы чужой ввод не видят.
- Пока слово набирается, демон копит **сканкоды**, а не символы. Одно и то же слово можно прочитать в любой раскладке.
- На пробеле или знаке препинания слово проверяется: есть ли оно в словаре текущего языка.
  Если нет, но в другой раскладке получается словарное слово (или, для длинных слов,
  оно заметно правдоподобнее по триграммной модели), демон стирает слово, переключает раскладку
  через D-Bus KDE (`org.kde.keyboard /Layouts`) и печатает его заново.
- Словари — частотные списки по 50k слов (OpenSubtitles 2018, [FrequencyWords](https://github.com/hermitdave/FrequencyWords)), встроены в бинарник.
  Плюс редкие словоформы из полных списков (`data/*_extra.txt`, `scripts/extra_words.py`) и IT-жаргон
  (`data/*_jargon.txt`: коммит, деплой, запушить…) — такие слова не «исправляются».
- Свои слова — `~/.config/layswitch/words.txt` (меню трея «Мои слова…»), по одному или через пробел.
  Они не исправляются и служат целью переключения (`rjvvbn` → `коммит`). После правки — `systemctl --user restart layswitch`.

## Клавиши

| Клавиша       | Действие |
|---------------|----------|
| `Pause`       | откатить последнее автоисправление (слово попадёт в `~/.config/layswitch/ignore.txt` и больше не исправляется); иначе перевести текущее/последнее слово в следующую раскладку |
| `Shift+Pause` | выключить/включить автопереключение (например, перед вводом пароля) |
| `Ctrl+Pause`  | перепечатать выделенный текст в другой раскладке (нужен `wl-clipboard`) |

Клавишу можно сменить в конфиге (`hotkey = "KEY_F12"` и т.п.).

## Иконка в трее

- Цветная клавиатура — автопереключение включено, перечёркнутая — выключено. Левый клик переключает.
- В подсказке при наведении — последнее исправление («ghbdtn → привет»).
- Меню: автопереключение, исправление опечаток (переключатель действует до перезапуска;
  насовсем — `autocorrect` в конфиге), «Исключения…», «Мои слова…», «Настройки…», «Выход».
- После «Выход» запустить снова: `systemctl --user start layswitch`.

## Установка

```bash
./install.sh
```

Скрипт собирает релиз, кладёт бинарник в `~/.local/bin`, ставит systemd user service и (через sudo):
- udev-правило, открывающее `/dev/uinput` группе `input`;
- добавляет пользователя в группу `input` (после этого нужно перелогиниться);
- `wl-clipboard`, если его нет.

Украинский: добавь раскладку «Українська» в «Параметры системы → Клавиатура → Раскладки»,
демон подхватит её сам (`layswitch layouts` покажет, что видно).

## Команды

```bash
layswitch               # демон (обычно запускается systemd)
layswitch layouts       # раскладки KDE и какая активна
layswitch check ghbdtn руддщ nginx   # что детектор сделал бы со словами
layswitch eval          # оценка модели на словах вне словаря
journalctl --user -u layswitch -f    # лог исправлений
```

## Конфиг

`~/.config/layswitch/config.toml`, пример с комментариями — `dist/config.toml`.

## Ограничения

- Демон не видит, в каком окне фокус и что это поле пароля. Перед вводом пароля жми `Shift+Pause`.
- Буфер слова сбрасывается при клике мышью, Ctrl/Alt/Meta-комбинациях, стрелках, Enter и автоповторе клавиши.
  Если курсор сдвинули иначе (например, тачпадом без клика), исправление может стереть не то.
- Индикатор Caps Lock на клавиатуре зеркалируется вручную и может рассинхронизироваться.
- Группа `input` даёт любым программам пользователя доступ к вводу с клавиатуры: это цена работы на уровне evdev.
- Если демон завис (не упал), клавиатура не работает: `systemctl --user stop layswitch` мышью из терминала или с другого TTY.
