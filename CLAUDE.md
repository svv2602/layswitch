# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

`layswitch` — демон на Rust, автоматически переключающий раскладку (en/ru/uk) в KDE Plasma под Wayland, в духе Punto Switcher: набрал `ghbdtn` + пробел → слово стёрто, раскладка переключена, напечатано `привет`. README на русском; код и комментарии — на английском.

## Команды

```bash
cargo build                      # edition 2024, нужен свежий stable toolchain
cargo test                       # все тесты; KDE/uinput не нужны (используется фейковый System)
cargo test end_to_end            # один тест по имени (engine.rs / detect.rs / layout.rs / dict.rs)
cargo run -- check ghbdtn руддщ nginx   # что детектор сделает с каждым словом
cargo run -- eval                # доля ложных переключений / исправлений LM-фолбэка на словах вне словаря
cargo run -- layouts             # раскладки KDE через D-Bus (нужна запущенная сессия Plasma)
./install.sh                     # release-сборка → ~/.local/bin, systemd user service, udev-правило, группа input (sudo)
journalctl --user -u layswitch -f   # лог: каждое исправление ("ghbdtn" -> "привет", typo "x" -> "y")
```

Сам демон (`cargo run` без аргументов) захватывает все физические клавиатуры. Если он завис — клавиатура мертва: `systemctl --user stop layswitch` / Ctrl+C мышью или с другого TTY. Если установленный сервис запущен, сначала остановить его, иначе два экземпляра дерутся за устройства.

## Архитектура

Поток данных: физические evdev-устройства → потоки `devices.rs` → `mpsc`-канал `Msg` → единственный главный цикл `main.rs::run` → `Engine::handle_key` → виртуальная uinput-клавиатура.

- **`devices.rs`** — поток-сканер каждые 2 с опрашивает `/dev/input` (hotplug). Клавиатуры захватываются через `EVIOCGRAB` (после ожидания отпускания всех клавиш), каждая клавиша уходит как `Msg::Key`; кнопки мыши/относительные события от захваченной клавиатуры (комбо-устройства) пересылаются кадрами `Msg::Pointer` на отдельный виртуальный указатель. Обычные мыши не захватываются, только слушаются ради `Msg::Click`, который сбрасывает буфер слова. `Leds` держит вторые хэндлы, чтобы вручную зеркалировать Caps Lock.
- **`engine.rs`** — конечный автомат нажатий, обобщённый по трейту `System` (эмит клавиши, получить/установить раскладку KDE, уведомления, primary selection, обновления трея…). `main.rs::Desktop` — настоящая реализация; `engine::tests::Field` — фейковое текстовое поле, интерпретирующее эмитированные клавиши в активной раскладке, так что end-to-end поведение тестируется без железа. Движок копит **strokes** (`(KeyCode, shift)`), а не символы, поэтому слово можно декодировать в любой раскладке. На триггере (пробел/пунктуация) спрашивает детектор, затем стирает бэкспейсами, переключает раскладку, делает `settle()` и переигрывает strokes. `Shown` помнит последнее завершённое слово для отката/ручной конвертации хоткеем. Буфер сбрасывается на аккордах, стрелках, Enter, автоповторе, кликах.
- **`detect.rs`** — `Detector::decide(strokes, caps, cur, layouts, recent)` → `Option<Switch>`: оставить слово, если оно есть в словаре текущего языка; иначе переключить, если другая раскладка даёт словарное слово, либо (для слов ≥ `min_lm_len`) триграммная LM-оценка лучше текущей на `lm_margin`. `recent` разрешает ничьи ru/uk. Там же `typo_fix` (опечатки в одну букву, по умолчанию выключено).
- **`dict.rs`** — частотные списки по 50k слов из `data/*.txt` встроены через `include_str!`; строятся карты рангов и символьная триграммная модель (`CharModel`) на язык. Слова длиной 1–3 считаются известными только при достаточно высоком ранге (в списках много мусора); есть явные allow-листы однобуквенных слов и английских суффиксов сокращений (списки токенизированы как `don` + `'t`). Плюс `data/*_extra.txt` — редкие словоформы (≥5 букв) из полных списков FrequencyWords, генерируются `scripts/extra_words.py`: они делают слово «известным» (блокируют typo-fix и переключение, годятся как цель переключения), но никогда не предлагаются как исправление опечатки. Короткие слова туда не берутся намеренно — иначе `dfc`/`ldf` из мусора блокировали бы `вас`/`два`.
- **`layout.rs`** — захардкоженные таблицы клавиша→символ, повторяющие xkb `us`, `ru` (winkeys), `ua` (unicode); `encode`/`decode` между текстом и strokes; `Lang::from_xkb` маппит короткие имена KDE. Раскладки KDE кроме en/ru/uk становятся `None` и пропускаются.
- **`kde.rs`** — блокирующие zbus-вызовы к `org.kde.keyboard /Layouts` (`getLayoutsList`, `getLayout`, `setLayout`) и freedesktop-уведомления. Таймаут метода 300 мс намеренно: пока ждём, клавиши задержаны. Список раскладок перечитывается не чаще раза в 10 с.
- **`tray.rs`** — трей через ksni (StatusNotifier); действия меню возвращаются в главный цикл как `Msg::Tray(Command)`.
- **`config.rs`** — `~/.config/layswitch/config.toml` (все ключи опциональны, пример с комментариями — `dist/config.toml`) и `ignore.txt` (слова, откатанные хоткеем; автоматически больше не трогаются).

Всё, что блокирует главный цикл (D-Bus, `wl-paste` для Ctrl+хоткея, `switch_delay_ms`), замораживает набор текста, поэтому у внешних вызовов жёсткие таймауты — так и держать.

Хоткей (по умолчанию `KEY_PAUSE`): просто — откат последнего автоисправления / конвертация текущего или последнего слова; Shift — вкл/выкл автопереключение; Ctrl — перепечатать выделенное (primary selection) в другой раскладке (нужен `wl-clipboard`).

## Настройка детекции

После изменения `lm_margin` / `min_lm_len` / логики словарей — `cargo run -- eval` (сравнивает margin 0.75/1.0/1.25, обучаясь на первых 30k слов и тестируя на остальных) и `cargo test` (в `detect::tests` кейсы «обязан переключить» / «обязан оставить»: `nginx`, `kubectl`, `don't`). Реальные ложные срабатывания удобно брать из `journalctl --user -u layswitch`.
